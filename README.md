# MSME Digital Assistant

A responsive Next.js product showcase for the Windows desktop edition of MSME Digital Assistant. It includes scroll-linked CSS 3D motion, an interactive assistant preview, and vector screen previews based on the supplied workspace screenshots.

An download preview, and live at ""
## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

The Windows setup download is stored at `public/downloads/MSME Digital Assistant_0.2.0_x64-setup.exe` and linked directly from the site to this repository's `main` branch. Update the download URL in `src/app/page.tsx` when publishing a new installer filename or version.
